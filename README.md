# Arthala Allaiah Trust — React + Vite scaffold

Simple React + Vite scaffold for the trust website.

Getting started:

1. npm install
2. npm run dev

Place real images in public/images (logo.png, hero.jpg, anna-prasadam.jpg, education.jpg, blood-donation.jpg, eye-checkup.jpg, books-donation.jpg) and update contact details in src/pages/Contact.jsx.
